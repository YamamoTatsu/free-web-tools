# 日本語ツールボックス

日本語ユーザー向け無料Webツールサイトの初期版です。第1弾として、ブラウザだけで動作する「高機能文字数カウンター」を収録しています。

## 特徴

- 入力と同時に8種類の数値をリアルタイム集計
- 読了時間と音読時間の目安を表示
- 入力例、全文コピー、全文消去に対応
- ボタン操作の結果を画面とスクリーンリーダーへ通知
- PC・スマートフォン対応
- 登録、通信、外部API、外部ライブラリは不要
- 入力内容を保存せず、外部へ送信しない設計

## ファイル構成

- `index.html`：ページ構造、説明、使い方、FAQ、プライバシー、免責事項
- `styles.css`：レイアウト、配色、レスポンシブ表示、フォーカス表示
- `app.js`：集計、時間計算、コピー、消去、通知
- `README.md`：仕様、使い方、テスト結果

## 集計の定義

文字数は、JavaScriptのUTF-16コードユニット数ではなく、`for...of`によるUnicodeコードポイント単位で数えます。そのため、一般的な絵文字は1文字です。複数のコードポイントを組み合わせた絵文字や結合文字は複数文字になる場合があります。

| 項目 | 定義 |
|---|---|
| 総文字数 | 横方向の空白と改行を含む、すべてのUnicodeコードポイント数 |
| 空白を除いた文字数 | 半角・全角スペース、タブなどの横方向の空白を除く。改行は含む |
| 改行を除いた文字数 | 改行を除く。横方向の空白は含む |
| 空白と改行を除いた文字数 | 横方向の空白と改行の両方を除く |
| 行数 | 空文字は0行。それ以外は改行数＋1。空行を含む |
| 空行を除いた行数 | 空白しかない行も空行とみなして除く |
| 段落数 | 1行以上の空行で区切られた、内容のある行のまとまり |
| UTF-8バイト数 | 改行をLFへ統一した後、`TextEncoder`で計測 |

CRLF、CR、LF、Unicodeの行区切り・段落区切りは、集計前にLFへ統一します。

## 時間計算

時間は「空白と改行を除いた文字数」を基準に、秒単位で切り上げます。

- 読了時間：1分あたり500文字
- 音読時間：1分あたり300文字

文章の難易度、読み手、間の取り方などにより、実際の時間は変わります。

## 開き方

1. このフォルダにある `index.html` を見つけます。
2. `index.html` をダブルクリックします。
3. 通常使っているブラウザで文字数カウンターが開きます。
4. 入力欄に文章を入力するか、「入力例をセット」を押して動作を確認します。

特別なソフトのインストールやサーバーの起動は不要です。

追加で、HTML・CSS・JavaScriptの静的検査により次の点を確認しています。

- 入力イベントから全指標と時間表示の更新処理が呼び出される
- 入力例・全文コピー・全文消去の各ボタンに処理と通知が設定されている
- 通知領域に`aria-live="polite"`が設定されている

- `eval`、`innerHTML`、ネットワーク通信、ブラウザ保存機能を使用していない

## プライバシーとデータ保存

集計処理はすべてブラウザ内で完結します。入力内容をネットワークへ送信する処理、Cookieやローカルストレージへ保存する処理はありません。ページの再読み込みまたは終了で入力内容は消えます。

## 対応環境

`TextEncoder`、`requestAnimationFrame`、Unicode対応のJavaScript構文を利用できる、現在の主要なブラウザを想定しています。古いブラウザでは動作しない場合があります。

## 免責

提出先や外部サービスによって文字数の定義が異なる場合があります。重要な用途では、利用先の規定と実際の入力画面でも最終確認してください。
