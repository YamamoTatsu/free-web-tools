# Hold'em Study Lab

PC・スマホ対応のテキサスホールデム学習用PWAです。

## 機能
- 6MAX / 9MAXのプリフロップ基準レンジ
- ポジション、スタック、オープンサイズの調整
- 対オープンの基準アクション
- 1〜3人相手のモンテカルロ・エクイティ計算
- 25 / 33 / 50 / 75 / 125%ポットの簡易EV比較
- ランダム問題演習
- localStorageへの履歴保存とJSON書き出し
- PWA対応

## 公開方法
GitHubリポジトリの任意フォルダへ、このフォルダ内のファイルをそのまま配置してください。
GitHub Pagesを有効にすると、友人へURL共有できます。

## 注意
プリフロップ戦略は学習用基準であり、厳密なソルバー解ではありません。
ポストフロップEVは、相手のランダムレンジと指定したフォールド率に基づく簡易モデルです。
リアルタイムプレー補助ではなく、プレー後の学習・復習用途を想定しています。
